# How do the Launchkey's Loop prefix and pads display and set Loop?

## Question

With a Launchkey button acting as the Loop prefix, how do the pads show the active (or a chosen) program's current Loop, and how does pressing a pad set it? Which values do the pads map to (e.g. 1–16 beats, or beats in the top row and measures in the bottom), and how is "no loop" chosen? Does the prefix target the selected program or the next pad pressed? How is a value the pads can't show displayed? What does that button's LED show at rest? First settle which button is the prefix: Loop (CC 118, white LED) or Function (CC 105, RGB; it is freed when the app-wide Loop goes). Loop's hardware label now matches the glossary term. Prototype the pad layout so it can be reacted to.
