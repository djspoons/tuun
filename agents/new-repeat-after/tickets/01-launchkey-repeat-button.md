# Which Launchkey control is the Repeat button, and what can we do with it?

## Question

The plan is to use the Launchkey's repeat button as a prefix key. Which physical control is it on the Launchkey models tuun supports (see `src/lib/launchkey.rs`)? What does it send in device DAW mode (CC or note number, channel, port)? Does it send both press and release? Can its LED be set, and with what colours or brightness? Is it already used by the device firmware in a way that conflicts with DAW mode? And how many pads, in which rows, could display and set a Repeat value while the prefix is pending?
