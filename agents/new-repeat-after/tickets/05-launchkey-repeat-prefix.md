# How do the Launchkey's Repeat prefix and pads display and set Repeat?

## Question

With the repeat button acting as a prefix key, how do the pads show the active (or a chosen) program's current Repeat, and how does pressing a pad set it? Which values do the pads map to (e.g. 1–16 beats, or beats in the top row and measures in the bottom), and how is "no repeat" chosen? Does the prefix target the selected program or the next pad pressed? How is a value the pads can't show displayed? What does the repeat button's LED show at rest? Prototype the pad layout so it can be reacted to.
