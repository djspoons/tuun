# When does a changed Repeat take effect on a program that is already repeating?

## Question

If a program's Repeat is edited (from the keyboard, from the Launchkey, or by editing its text) while it is repeating, does the new value apply to the voices already scheduled, at the next repeat, at the next measure, or only at the next launch? What happens when the annotation is removed while the program is repeating: does it stop after the current play? Is the answer the same for sequencer programs?
